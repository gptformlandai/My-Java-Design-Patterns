# Web, Presentation, and UI Patterns

This folder contains one focused learning module per web, presentation, and UI design pattern.

## Recommended Study Order

| Priority | Pattern | Module |
|---|---|---|
| Very High | Model-View-Controller | [model-view-controller.md](model-view-controller.md) |
| High | Front Controller | [front-controller.md](front-controller.md) |
| High | Intercepting Filter | [intercepting-filter.md](intercepting-filter.md) |

## Module Format

Each pattern module includes:

- How to study the page
- Technical definition
- 30-second interview answer
- Layman definition
- Bit by bit explanation
- Java and Python examples
- Real-world use cases
- Advantages over normal code
- Where it excels and fails
- Helpful frameworks/libraries
- Pros and cons
- Real-world identification scenario
- Interview triggers
- Common mistakes
- Pattern comparisons
- Design checklist
- Quick revision notes
- Mini exercise
- Source reference in this repo
