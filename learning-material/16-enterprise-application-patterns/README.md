# Enterprise Application Patterns

This folder contains one focused learning module per enterprise application pattern.

## Recommended Study Order

| Priority | Pattern | Module |
|---|---|---|
| Very High | Data Transfer Object | [data-transfer-object.md](data-transfer-object.md) |
| Medium | Registry | [registry.md](registry.md) |
| Medium | Service Locator | [service-locator.md](service-locator.md) |

## Module Format

Each pattern module includes:

- How to study the page
- Technical definition
- 30-second interview answer
- Layman definition
- Bit by bit explanation
- Java and Python examples
- Real-world use cases
- Advantages over normal code
- Where it excels and fails
- Helpful frameworks/libraries
- Pros and cons
- Real-world identification scenario
- Interview triggers
- Common mistakes
- Pattern comparisons
- Design checklist
- Quick revision notes
- Mini exercise
- Source reference in this repo
